# Desire System Skill

这是一个基于用户提供的《给 AI 装一套「欲望」：跑了三个多月之后的攻略》（小红书版 v2，2026-09-17）整理的通用 Agent Skill。

## 文件
- `SKILL.md`：技能定义与行为/实现指南。

## 使用
将 `desire-system` 文件夹放入支持 Agent Skills 的宿主应用的 skills 目录，或上传 `SKILL.md` 到支持自定义技能/指令的工具中。不同宿主的安装路径和元数据要求可能不同。

## 说明
本 Skill 将原文机制整理为可实施规范，并补充了权限、隐私、反操纵和生产/测试隔离的工程护栏。原文中的参数是参考起点，不保证适合所有应用。该 Skill 本身不会自动提供定时器、浏览器、数据库或工具调用能力；这些需要宿主应用实现。
